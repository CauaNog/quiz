QUIZ DE ANATOMIA MUSCULAR — JAVASCRIPT

COMO EXECUTAR
1. Extraia o arquivo ZIP para uma pasta.
2. Abra a pasta quiz_anatomia_muscular_js.
3. Dê dois cliques em index.html para abrir no navegador.
4. Se o navegador bloquear algum recurso local, abra a pasta no VS Code e use a extensão Live Server.

ARQUIVOS
- index.html: estrutura da página.
- css/style.css: aparência e responsividade.
- js/facts.js: dados anatômicos de referência.
- js/questions.js: geração e validação do banco de questões.
- js/app.js: lógica do quiz, cronômetro, correção e recordes.

RECURSOS
- Banco com mais de 100 perguntas geradas dos dados anatômicos cadastrados.
- Níveis fácil, médio e difícil.
- Modo treino com explicações e simulado corrigido ao final.
- Cronômetro para simulados.
- Recordes salvos no localStorage do navegador.
- Funciona sem servidor e sem conexão com a internet.

OBSERVAÇÃO
Os recordes ficam no navegador atual e não são sincronizados entre dispositivos.
O banco de questões é gerado a partir dos músculos cadastrados em js/facts.js; revise o conteúdo anatômico com o material da disciplina antes de usar como avaliação formal.
